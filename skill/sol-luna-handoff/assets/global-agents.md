## Sol-Luna project workflow

For every task that creates, modifies, fixes, refactors, reviews, tests, or configures software or project artifacts, including project documentation, you must load and follow `$sol-luna-handoff`. Let the Skill select its Tier 1, Tier 2, or Tier 3 Sol-Luna route and advance automatically without pausing for routine confirmation.

This rule excludes general Q&A, translation, and prose-only work that does not modify a project artifact.
