## Sol–Luna project workflow

For every task that creates, modifies, fixes, refactors, reviews, tests, or configures software or project artifacts, including project documentation, you must load and follow `$sol-luna-handoff`. Route the work through Sol planning, Luna execution, and Sol verification, and advance automatically between stages without pausing for routine confirmation.

This rule excludes general Q&A, translation, and prose-only work that does not modify a project artifact.
